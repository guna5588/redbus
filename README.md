# 🚌 RedBus Data Scraping & Dynamic Filtering System



A complete Data Engineering and Data Visualization project built using **Python, Selenium, MySQL, Pandas, Plotly, and Streamlit**.



This project scrapes bus travel data from RedBus, stores it in MySQL, and provides an interactive Streamlit dashboard for dynamic filtering, analysis, and visualization.



---



# 📌 Project Overview



The objective of this project is to:



- Scrape live bus data from RedBus using Selenium

- Store the scraped data into MySQL database

- Build an interactive Streamlit dashboard

- Perform dynamic filtering based on:

  - Bus type

  - Ticket fare

  - Ratings

  - Government/Private ownership

  - Time ranges

  - Bus routes

- Generate analytical visualizations using Plotly
